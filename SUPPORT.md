# Support

Use [GitHub Issues](https://github.com/AlinTibi/ConfigDoctor/issues) for bugs and feature requests. Include your application/Windows version, format and a minimal reproduction using fake configuration values.

General support: **support@almarfeld.com**. Contact: **contact@almarfeld.com**. Security reports: follow [SECURITY.md](SECURITY.md).

Never share real credentials or private configuration files in an issue or screenshot.
